# SiliconPath — Free VLSI Learning Platform

[![Deployed on Vercel](https://img.shields.io/badge/Deployed-Vercel-black)](https://siliconpath.vercel.app)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

SiliconPath is a 100% free learning platform for VLSI and semiconductor engineers. No paywalls, no premium tiers, no course selling.

## Features

### Learning Academy
- **7 structured learning tracks** with day-by-day curriculum
- Practice quizzes and assessments
- Progress tracking
- YouTube video embeds

### 15 Learning Paths
- **Foundation:** Digital Electronics, Verilog HDL, CMOS VLSI Design, FPGA Design, Embedded Systems
- **Backend:** ASIC Physical Design, STA & Timing, DFT, Verification, Analog IC Design, Custom Layout
- **Tools & Career:** EDA Tools, Scripting for VLSI, VLSI Career Roadmap, Interview Preparation
- **148 total modules** with theory, examples, and practice

### Engineering Lab
- 4 real-world violation debugging cases
- Timing violations, congestion, DRC errors
- Step-by-step walkthroughs

### STA Interview Questions
- 128 questions across 11 topics
- Expandable answers with code examples

### Free Resources
- OpenLane RTL-to-GDS guide
- VLSI Career Roadmap
- Resume Tips for VLSI engineers

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **UI:** React 18 + TypeScript + Tailwind CSS
- **Database:** Supabase (optional)
- **Hosting:** Vercel

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
cd frontend && npm run dev

# Open
http://localhost:3000
```
