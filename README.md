## 📌 Executive Summary

**BerojgarDegreeWala** is India's dedicated unified career portal and learning ecosystem built specifically for microelectronics, VLSI design, semiconductor manufacturing, and embedded systems engineers.

By combining multi-source official job aggregators, automated RSS news sync, structured VLSI Courses, candidate `@username` profiles, employer portals, and an AI-driven career assistant, BerojgarDegreeWala bridges research institutions (**DRDO**, **ISRO**, **CSIR**, **IIT Bombay**, **IIT Madras**, **IISc**) with global semiconductor leaders (**Intel**, **Qualcomm**, **AMD**, **TSMC**, **Arm**, **Texas Instruments**, **Nvidia**, **Synopsys**, **Cadence**, **Tata Electronics**).

## ✨ Key Services & Features

### 🎯 1. Jobs & Opportunities (`/opportunities`)
- **Direct Official Verification**: Every listing links directly to official government recruitment portals (`rac.gov.in`, `isro.gov.in`, `csir.res.in`, `iitb.ac.in`) or verified corporate career pages.
- **Categorized Roles**: Junior Research Fellow (JRF), Senior Research Fellow (SRF), PhD Admissions, Government Scientist Recruitment, Private VLSI Engineering Jobs, and Internships.
- **Ponytail Lazy Loading**: Heavy interactive client components utilize `nextDynamic` loading for fast rendering and hydration safety.

### 📚 2. VLSI Courses (`/academy`)
- **Structured Self-Paced Curriculum**:
  1. *Digital Logic & SystemVerilog Fundamentals*
  2. *RTL Verification with SystemVerilog & UVM*
  3. *Physical Design, Floorplanning & Primetime STA*
  4. *FPGA Architecture, Xilinx Vivado & IP Cores*
  5. *RISC-V Microarchitecture & Custom Instruction Extensions*
  6. *Analog IC Design & Cadence Virtuoso Fundamentals*
- **Curated Open Resources**: Direct integration with NPTEL (IIT Kharagpur/Madras), ChipVerify masterclasses, HDLBits auto-graded labs, and OpenLANE Sky130 PDK flows.

### 🌐 3. Professional Network & Direct Messaging (`/network`, `/messages`)
- **Unique `@username` Profiles**: Candidates and researchers claim verified unique handles (e.g. `@ananya_vlsi`) for direct talent matching.
- **Employer Portals**: Organizations post JRF, PhD, and microelectronics roles under official organization handles.
- **Direct Messaging & Connections**: Connection management (`accepted`, `declined`) and real-time candidate messaging.

### 🛡️ 4. Standalone Admin Command Center (`/admin`)
- **Isolated Portal**: Fully separated from public website navigation with a dark executive theme (`Slate-950`).
- **25+ Monitored Scraper Sources & RSS Feeds**: Real-time sync logs for DRDO RAC, ISRO Careers, CSIR Labs, IIT Microelectronics, IEEE Spectrum, EE Times, Semiconductor Engineering, EDN, SemiWiki, and Electronics Weekly.

## ⚡ Quick Start & Development

### Prerequisites
- Node.js 18.x or 20.x
- npm / yarn / pnpm

### Installation & Execution
```bash
# Navigate to frontend directory
cd frontend

# Install dependencies
npm install

# Run development server
npm run dev

# Build production bundle
npm run build
```
