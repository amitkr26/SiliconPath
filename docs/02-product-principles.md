# 02 - Product Principles

These are non-negotiable. Any change that violates one of these is wrong by default.

1. **Never hide opportunities.** All verified opportunities are public.
2. **Registration is optional.** The aggregator and Academy work fully without an account.
3. **Search is always public.** No login wall on search or browse.
4. **Apply always redirects to source.** We never intermediate the application; we send users to the original posting.
5. **No resume upload required** to use the platform. The resume builder is opt-in.
6. **No dark patterns.** No fake urgency, no forced signups, no bait.
7. **No ads.**
8. **Mobile first.** Every page must be fully usable on a phone before it ships.
9. **Fast.** Server-render public pages; keep client bundles lean.
10. **Accessible.** Keyboard navigable, semantic HTML, sufficient contrast, 44px touch targets.
11. **Data quality is sacred.** A listing shows publicly only when it has a correct title, correct category, a real organization, and a working apply URL. Everything else stays `pending`.
12. **Worldwide by default.** No copy, schema, or filter assumes India-only.
