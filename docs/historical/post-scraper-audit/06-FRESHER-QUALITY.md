## 2. Degree & Eligibility Filter Validation

- **B.Tech / B.E.**: Queries match `B.Tech`, `BTech`, `Bachelor`, `B.E`, `BE` across `eligibility` and `title`.
- **M.Tech / M.E. / M.S.**: Queries match `M.Tech`, `MTech`, `Master`, `M.E`.
- **PhD / Research**: Queries match `PhD`, `Doctorate`, `JRF`, `Fellowship`.
- **Diploma / Apprenticeship**: Queries match `Diploma`, `Apprentice`, `Technician`.

All filters execute against live PostgreSQL columns rather than mock fixtures.
