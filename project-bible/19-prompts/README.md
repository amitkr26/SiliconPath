# Prompts (Historical Session Prompts)

## Overview

This directory holds the three session prompts that bootstrapped the codebase
and documentation. They are historical artifacts — kept for reference, not for
reuse as-is. The cataloged prompt library described in earlier versions of this
README does not exist yet.

## Existing Files (historical)

- `berojgardegreewala-kickoff-prompt.md` — initial project kickoff prompt
- `berojgardegreewala-phase1-db-backend-prompt.md` — Phase 1 database/backend prompt
- `berojgardegreewala-clickup-project-bible-prompt.md` — ClickUp project-bible generation prompt

## Not Yet Built

The prompt library (`development-prompts/`, `analysis-prompts/`,
`ai-gateway-prompts/`, `documentation-prompts/`) and its catalog do not exist.
When built, prompts should follow the AI Operating Manual
(`00-ai-operating-manual/`) and carry a YAML front-matter block (version,
last_updated, author, status, applies_to).
